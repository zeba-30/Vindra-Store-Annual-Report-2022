# Vindra Store Annual Report (2022) - Data Analysis Dashboard

A comprehensive Excel dashboard and data analysis report built for Vindra Store to visualize annual sales, customer demographics, and order channels for 2022.

## 📊 Dashboard Overview
The dashboard provides actionable insights into business performance across several key dimensions:
* **Orders vs. Sales Trends:** Tracks monthly fluctuations in revenue and order volumes throughout the year.
* **Sales by Gender:** Breaks down purchasing share between Men and Women.
* **Order Status:** Summarizes fulfillment outcomes, including Delivered, Refunded, Returned, and Cancelled orders.
* **Top 5 States:** Highlights the highest-performing regions by sales volume, including Maharashtra, Karnataka, Uttar Pradesh, Telangana, and Tamil Nadu.
* **Age vs. Gender Demographics:** Analyzes customer segmentation across Adult, Senior, and Teenager age groups.
* **Sales Channels:** Compares performance across platforms like Amazon, Flipkart, Myntra, and Meesho.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Used for data cleaning, pivot tables, formulas, and interactive dashboard design.
